补充章节一 Kali实战

1. 实际应用场景题目

公司的一名运维人员Lama发现其管理的服务器遭到黑客入侵，并植入了后门和木马。由于该服务器存在已久，Lama忘记了其IP地址和登录密码。

请你协助协调处理此事：首先定位该服务器并记录相关信息，然后进行应急排查，找出并删除木马文件，恢复系统的正常运行。

具体原理：

Kali虚拟机作为排查问题的工具电脑（模拟黑客入侵），netdiscover 是一个被动/主动 ARP 探测工具，它的原理是：

Kali 在局域网里发广播包（ARP 请求），问：“谁在 192.168.117.x 这个网段？请回答你是谁？”

所有在线的主机都会自动回应（这是网络协议的规定，不需要密码）

Kali 收集这些回应的 MAC 地址和 IP 地址，列成一张表显示给你

这个模拟实验的本质 = 用 Kali 虚拟机（模拟攻击者/工具机）去访问/探测 真实物理机/主机（模拟受害者服务器）

3）真实情况下，是不能用这种方法来获取受害者电脑的Ip地址的

4）kali虚拟机要想扫到主机的IP地址，必须用桥接模式(不能用net模式和仅主机模式)，这样能够保证kali的IP地址和主机的IP地址处于同一个网段

5）建议kali虚拟机设置双网卡模式

双网卡会增加难度，需要什么模式可以随时更换，

6）/24 叫做 CIDR 前缀长度（Classless Inter-Domain Routing），它告诉计算机：这个网段有多大。（规定了扫描范围，把搜索圈定在了 192.168.1.0 ~ 192.168.1.255 这个区间里）

简单来说，/24 就是子网掩码 255.255.255.0 的简写。

解决方法

第一步

查看kali虚拟机的Ip地址，打开终端，输入sudo su root，切换到管理员权限，输入ifconfig。

（没有 ipconfig 这个命令（这是 Windows 的命令），Linux 系统里用的是 ifconfig）

比如：目前我的kaliI IP地址为：192.168.1.163

第二步

因为靶机和kali属于同一个网段，所以靶机的IP地址也是【192.168.1.163】这个网段，

我们使用局域网发现工具进行探测靶机的IP地址探测。

终端输入命令: sudo netdiscover -r 192.168.1.0/24 （注意只有3个空格，sudo就是以最高权限去运行）

扫描出来同一网段的东西（比如 192.168.1.13，那么被入侵的那台电脑（主机）的IP就是其中之一，至于怎么判断，......）

第三步

1）获取完主机的IP地址后，接下来就是对靶机的IP地址进行扫描，在Kai中可以使用NMAP工具进行扫描

Nmap是不少黑客及脚本小子爱用的工具，可以检测目标主机是否在线、端口开放情况、侦测运行的服务类型及版本信息、侦测操作系统与设备类型等信息。

2）一台电脑有65535个端口，

知名端口（0 — 1023）：“固定的政府/机构大楼”

特点：全世界统一规定，固定分配给特定的顶级服务。普通程序不能用，只有管理员（root）权限才能启动。

作用：让客户端不用问就知道去哪里找服务。



注册端口（1024 — 49151）：“公司/软件专属办公区”

特点：需要向 IANA（互联网数字分配机构）申请注册，但不像知名端口那么死板。某些大型软件或游戏会固定占用这里。

作用：给知名软件用的“固定门牌号”



动态/私有端口（49152 — 65535）：“临时访客/随机门牌号”

特点：随机分配，不需要申请。不固定绑定任何服务。

作用：当你的电脑访问百度（目标 80 端口）时，系统会随手抓一个这里面的空闲数字（比如 52341）作为临时门牌号，用来接收百度返回的数据。用完就释放，下次访问换个号码

3）kali中nmap扫描

sudo nmap -O 192.168.1.13（主机防火墙会拦截）

4）获取对方电脑的账号密码，账号Lama，密码用暴力破解

> Kali中，可以使用medusa工具，Medusa(美土莎)是一个速度快，支持大规模并行，模块化，爆破登录。可以同时对多个主机，用户或密码执行强力测试。根本原理是暴力破解，需要有密码字典（密码字典可以从外面传，也可以在kali浏览器里面下载，最后放到桌面上）。

> “美杜莎”（Medusa）是Kali Linux自带的一款命令行密码爆破工具，它的设计目标就是运行在Linux和macOS这类操作系统上，Windows系统无法直接安装和使用它。

> 至于美杜莎在Kali中的命令，可以去问AI

出现 [SUCCESS]，说明破解成功了

5）远程登录对方电脑

获取完，账号、密码、IP地址后，在kali里面输入 ssh 用户名@192.168.1.13

然后输入密码（刚刚暴力破解得到的）

这样就登录了对方电脑（终端）

接下来就可以排查，找木马，恢复系统了

2. Linux系统本地入侵排查流程

-Linux入侵前的信息收集的一些命令



cat /etc/passwd 这个命令得到的0~1000是系统内置的，1000以上基本上就是黑客留的（就要把黑客留的删除）

netstat -lntp 查看端口（比如：80，8080，443，3306，22，53）

ps -aux | grep 9999 查看哪个程序运行了9999端口

3. Linux恶意用户排查和清除（删除黑客留下的数据）

> 在Linux系统中,存在着两个特殊的文件cat /etc/passwd 和cat /etc/shadow 这两个文件中存储着用户名和加密后的密码.

在目前大多数Linux系统中,将加密后的用户密码存放在 /etc/shadow 中但是 /etc/shadow 只能 root 用户查看

> cat /etc/passwd，1000以上就是黑客留下的，给删掉

删除的方法，root权限下，执行命令 userdel -r 用户名 （ 用户名是刚刚检测到的，

比如userdel -r losy ）

可以一个一个删，也可以一次性全部删完（不建议）

> 有些时候程序正在运行(userdel -r losy 为例)，需要把程序/端口关闭，才能正常删除用户

---

---

接下来讲解，怎么关闭正在运行的程序

> 计划任务，

就是按照规定的计划时间，执行固定的程序，

当我们需要在服务器上定时执行一些重复性的事件时使用的，

可以通过计划任务程序来运行准备好的脚本、批处理文件夹、程序或命令，在某个特定的时间运行。

> 计划任务的文件夹，root权限下，ls /etc/cron*、cat /etc/crontab







这些都是时间点，任务到了这个时间点，就开始跑一次

如果是 ***** ，说明每隔一分钟，该程序就跑一次

> 这样可以通过计划任务，查看 用户losy的程序 是何时运行的，然后想办法关闭

--(B站课程)root权限下执行 cd /opt/web 然后ls ，这时候出现index.php文件，说明黑客留了一个后门，以后可以通过9999端口，通过index.php，进入该受害者电脑 进行控制

--然后cat index.php（cat ...就是查询的意思），里面是一串代码，说明index.php是一个木马（webshell）

> 接下来我们要做的就是，删除文件index.php，然后把losy(黑客名)的计划任务停止

# rm index.php （删除文件）

# ls

# vim /etc/crontab （清理/删除计划任务进程，其实没木马了，任务可删可不删，保险起见，还是删了好）

这时候，鼠标移动到最后一行第一个字符，双击键盘”DD”，

最后 :Wq! 保存一下

<hr class="content-hr">

以上操作，是关闭了losy正在运行的程序

这个时候可以，root权限下，# userdel -r 黑客名(losy) ，删除用户



发现不行，因为losy的程序已经运行了很多了，我们现在需要把 已经运行的程序给结束掉

# ps -aux | grep 9999（查看）

# kill -9 2007

<如果有更多的，比如2009 2014等等，重复一样的方法/操作，都给他们删除了>

这个时候，root权限下，# userdel -r 黑客名(losy) ，即可删除用户

现在 # cat /etc/passwd 查看到电脑里面没有黑客文件/程序了

4. Sudo配置修改

黑客程序删干净之后，由于黑客程序的运行，会导致sudo配置出现错误，这时候需要修改过来。

> root权限下，终端输入 # vim /etc/sudoers，把里面不顺眼的删掉，比如:losy等有关黑客的东西，通常只留下一个root 相关的（删掉某一行，将鼠标放到该行的第一个字符位置，键盘敲”DD”，即可删除）

然后保存 :Wq!

> 可以再看一下 # vim /etc/sudoers ，查看是否删除干净

> 接下来重新打开一个新终端，不一定非要root权限，（比如ssh lama@192.168.41.137），我的kali是ssh root@192.168.1.163（ssh命令是远程连接，端口22，当然也能连接自身）

然后sudo -l

发现用户lama没有权限了，说明已经恢复了
