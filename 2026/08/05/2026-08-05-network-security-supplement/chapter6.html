<h1 class="chapter-main-title">第十二章 XSS漏洞 </h1> <h3 class="section-title">1. 如何远程触发浏览器的弹窗？</h3>

> 核心条件只有一条：

必须在对方的浏览器里，执行一段 JavaScript 代码。

> 因为浏览器弹窗alert(), confirm(), prompt()是 JavaScript 的固有功能，只要代码能跑起来，弹窗就会出现。

> 你是否能让对方的浏览器运行你的 <script> 标签或 JS 函数”。只要你能做到这一点，弹窗就实现了

<h3 class="section-title">2. 什么是XSS漏洞？</h3> <li class="content-list-item">--XSS（Cross Site Scripting）：跨站脚本攻击，为了不和”层叠样式表”（Cascading StyleSheet s）的缩写CSS混合，所以改名为XSS。</li> <li class="content-list-item">--XSS原理：攻击者在网页中嵌入客户端脚本（通常是JavaScript的恶意脚本），当用户使用浏览器加载被嵌入恶意代码的网页时，恶意脚本代码就会在用户的浏览器执行，造成跨站脚本攻击。</li> <li class="content-list-item">--XSS漏洞.常出现的场景（只要能够输入，就可能有XSS）</li>

重灾区：评论区、留言区、个人信息、订单信息等

针对型：站内信、网页即时通讯、私信、意见反馈等

存在风险：搜索框、当前目录、图片属性等

<h3 class="section-title">3. XSS分类</h3>

XSS 主要分为三类：反射型、存储型、DOM 型。

<li class="content-list-item">---</li>

> 反射型 XSS（非持久型）

特点：恶意脚本通过 URL 参数传递，服务器收到后直接拼接在 HTML 里返回，只影响当前这一次访问。

例子： xss-labs.com:1027 第一、二、三关都是反射型。

常见场景：搜索框、URL 参数。

<li class="content-list-item">---</li>

> 存储型 XSS（持久型）

特点：恶意脚本被保存在服务器数据库中，每当有人访问包含该数据的页面时，脚本都会自动执行。影响范围大，所有访问者都可能中招。

例子：留言板、评论区、帖子标题——攻击者把 <script>alert(1)</script> 写在评论里，存储到数据库，之后每个打开该页面的人都会弹窗。

危害：比反射型大得多，因为它会“传染”。持久性和稳定性，危害最大。

<li class="content-list-item">---</li>

> DOM型XSS（基于文档对象模型，特殊的反射型）

特点：全程在浏览器前端发生，不需要经过服务器后端。恶意脚本通过修改页面 DOM 结构来执行。

例子：document.write(location.hash) 或 eval(location.href) 这类前端代码，如果没对用户输入做过滤，攻击者就能利用 URL 中的 # 后面的内容注入脚本。

区别：反射型和存储型需要服务器参与，DOM 型完全由前端 JavaScript 引起。

<h3 class="section-title">4. 如何检测/识别一个网站是否有XSS漏洞？</h3>

> 所有用户输入的地方都可能存在XSS

> 在输入框，输入<script>alert(123)</script>等，如果有弹窗123，说明具有XSS漏洞

> 借助工具来扫描，比如：burpsuite等（当然还有其他工具）

<h3 class="section-title">9. 工具：BeEF</h3>

> BeEF全称The Browser Exploitation Framework，是一款针对浏览器的渗透测试工具。

用Ruby语言开发的，用于实现对XSS漏洞的攻击和利用。

<li class="content-list-item">--BeEF不光是针对XSS漏洞的，如果一个网站上没有XSS漏洞，BEEF依然可以使用。但前提是需要有其他方式把 BeEF 的“钩子”（Hook）代码注入到受害者的浏览器中。</li> <hr class="content-hr">

本质上就是一种“钓鱼”（欺骗）。它属于客户端攻击，而不是针对服务器端漏洞的攻击。

> BeEF是怎么工作的？

简单概括为三个步骤：“撒钩子” -> “等上钩” -> “发指令”

工作原理是让受害者的浏览器（被称作“僵尸”）与BeEF的控制服务器建立一个持久的“双向通道”，然后由攻击者通过这个通道发送各种模块化的攻击指令

> BeEF的功能

信息搜集：可以实现网络发现、主机信息获取、cookie获取、会话劫持、获取键盘记录、获取插件信息等功能

持久化控制：可以实现确认弹框，小窗口和中间人攻击。

社会工程学攻击：可以实现点击劫持、弹窗告警、虚假页面和钓鱼页面等攻击

渗透攻击：可以实现内网渗透、CSRF跨站请求伪造攻击、DDOS攻击，还可以结合Metasploit Framework（MSF）使用

<li class="content-list-item">---</li>

BeEF，全称：Browser Exploitation Framework，中文翻译：浏览器利用框架

MSF，全称：Metasploit Framework，中文翻译：元利用框架（通常不直译，普遍直接称为 Metasploit 框架）

CS,全称：Cobalt Strike

中文翻译：通常不直接翻译，业内普遍直接称其为 Cobalt Strike。如果按字面意思，可以译作“钴打击”或“钴锤”，但在实际交流中几乎没人这么说。
