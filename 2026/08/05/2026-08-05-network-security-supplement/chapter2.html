> Apach 、Mysql、Nginx、、FTP这四个分别代表什么？
Nginx / Apache（网页服务器） = 门卫/接待员。它们负责接待访客（浏览器）的请求，并把网页内容发给访客。Nginx 像一位高效的前台，擅长同时处理大量访客；Apache 像一位功能强大的管家，配置灵活但人多时可能慢一些。
MySQL（数据库） = 档案库/仓库。它负责存储网站的所有数据，比如用户注册信息、文章内容、商品列表。你看到的动态内容（比如用户名、价格）都是从这里面调取出来的。
FTP（文件传输协议） = 搬运货物的后门。它不是网站运行必须的部分，而是一个上传工具。当你需要把网站代码、图片等文件从自己的电脑传到服务器上时，就需要通过FTP这个“搬运通道”。
真正搭建网站的时候FTP一般不需要

5. Sudo提权 获取root用户最高权限
> sudo介绍
SUDO是Linux系统管理指令，是允许系统管理员让普通用户执行一些或者全部的root命令的一个工具
在一些应用场景里面，为了方便运维人员以低权限帐号进行运维，往往会开启帐号的一些SUDO权限给运维帐号，从而减少root等登录频率
> 这里补充一下Linux系统常见的命令
（这里先记录一下常见命令，Linux操作系统作为一个大模块要单独学习）
面试官考Linux命令，核心就盯着文件管理、权限和状态排查。你不用全背，把这20个以内的高频命令及“考点”记牢就行：
• ---
cd / ls / pwd：切换、列表、显示当前路径。考点：ls -l 看权限，ls -a 看隐藏文件。
cp / mv / rm：复制、移动/重命名、删除。致命考点：rm -rf 慎用，面试必问“如何安全删除”（先ls确认再删）。
cat / less / tail：查看文件。考点：tail -f 实时看日志，绝对高频。
vim：编辑文件。考点：三种模式（命令/插入/底行），保存退出 :wq，强制退出 :q!。
chmod / chown：权限和归属。考点：chmod 755 的数字含义（属主7=rwx，属组5=rx，其他人5=rx）。
ps / top / netstat：看进程、看资源、看端口。考点：ps -ef | grep java 查进程，netstat -tlnp 查端口占用。
grep / find：文本搜索和文件查找。考点：管道符 | 组合使用，如 grep ERROR app.log。
df / du：看磁盘和文件大小。考点：df -h 看整体，du -sh * 看当前目录下各文件大小。
tar：打包压缩。考点：解压 tar -zxvf（z代表gzip，x解压，v显示，f文件）。
kill：终止进程。考点：kill -9 强制杀，kill -15 优雅终止（可被捕获清理资源）。
• ---
面试Linux操作系统，有3个必考题：
// 日志报错磁盘满？ 答：用 df -h 看分区，再用 du -sh * 找大文件，清空用 > filename。
// 端口被占用？ 答：netstat -tlnp | grep 8080 查PID，然后 kill -9 PID。
// 权限不够？ 答：加 sudo，或检查 ls -l 看属主，用 chmod 改权限。
• ---
最后记个“保命口诀”：增删改查用Tab补全，删前先看，改前先备份。
> 接下来将如何使用Sudo提权，获取root用户最高权限
先登录获取lama用户权限(这三个用户 哪个能行就用哪个，假设lama能行)——sudo -l 输入lama密码，查看——whoami 查看用户名(就是返回lama)——sudo whoami 返回root（不同的用户，不一定都返回root，要么返回root 要么命令执行失败或报错）——sudo id（id变成0，也就是最高权限）
总之，sudo xxxx ，就是在lama/... 用户权限下，以最高权限执行命令
（比如 sudo sqlmap -u）
> sudo su root 就是切换到最高权限（root权限）


6. Python建立反弹SHELL连接
上面讲到的，获取root权限必须用sudo ；那么我们不想用sudo，能不能直接获取root权限？
Python建立反弹SHELL连接
> Bash是许多Linux发行版的默认Shell，类似windows中的CMD命令行，使用Bash就可以启动一个Shell，从而执行操作系统的命令
我们可以通过Python执行Bash命令从而实现启动losy用户的Shell
> Shell 就是一个命令行解释器，webshell是网站木马

>具体操作：在 python3里面执行命令
import os
os.system("bash")
打开之后，就直接变成root权限

或者是，在普通用户权限下，直接执行 sudo bash，不用python，也能从普通用户
权限—root权限

> sudo滥用
Sudo滥用是root乱给的权限，它不是漏洞，而是管理员在配置root的时候配置的
普通用户默认不能使用 sudo，管理员可以通过配置主动赋予这个权限
• --
为什么必须给普通用户 sudo 权限？
因为 Linux 的设计原则是：
日常工作用普通用户（安全，防止误删系统文件）
需要管理操作时提权（通过 sudo 临时获得 root 权限）
• ---
如果不给 sudo 权限，普通用户连这些基础操作都做不了

7. Shadow文件和特权账号
你作为攻击方，受害者（Linux操作系统）已经发现你对其电脑/服务器/...做出了入侵、篡改、窃取数据等操作，然后受害者就开始修复这些问题（漏洞bug等）。
那么攻击方下一次要入侵电脑，就变得十分困难。
这个时候，攻击方可以考虑留一个后门，下次入侵的时候，直接通过这个后门进入受害者电脑。
Linux操作系统，留后门的方法有许多，这里将：特权账号留后门
• ---
> 在Linux系统中,存在着两个特殊的文件 /etc/passwd 和 /etc/shadow 这两个文件中存储着用户名和加密后的密码.
在目前大多数Linux系统中,将加密后的用户密码存放在 /etc/shadow 中，但是 /etc/shadow 只能root用户查看.
那么有了root权限后，就能查看 用户密码 了.
passwd文件里面存放着用户名，什么权限的用户都能查看 cat /etc/passwd，
> 如何提权到root权限，上面介绍了几种方法了
sudo提权、直接运行sudo bash、sudo su root、sudo + python提权、计划任务提权
这些都是普通用户获取权限——最高权限（root权限）的方法
kali虚拟机里面还能直接打开root终端，本质和sudo su root一样
• ---

特权账号的创建
> 比如说，我要在Linux操作系统（kali虚拟机）里面创建一个账号baili，并且获得最高权限
那么就需要
在/etc/passwd 和 /etc/shadow这两个文件里面添加baili的信息——把用户ID、组ID都改成0——
不建议 把root改成baili，

> PASS WD文件主要是存放账户的文件，任意用户都可以查看，格式如下
用户名：密码：U ID（用户ID）：GID（组ID）：描述性信息：主目录：默认Shell
> 创建用户需要用到的命令是
首先，root权限下，useradd xxxx （比如：usersdd baili 、 useradd test）
然后，查看cat /etc/passwd ，发现创建成功
////
下面这条命令能直接创建
useradd -p 'openssl passwd-1-salt 'salt' 123456' test -0 -u 0 -g root- G root -s /bin/bash -d /home/test
test是用户名，123456是密码，其余都是模板
查看cat /etc/passwd ，发现创建成功
复杂命令的话，直接提供用户名，剩下的让AI来写
> 创建完成后，名为test，实为root，仅仅是账号密码的区别。因为对于一台电脑而言，用户名ID:组ID=0:0 ，就是root（电脑默认的）
根据上述原理，说明bali创建后不易被发现和修复，那么就可以把baili作为 再次进入受害者电脑的后门，下次直接用该账号访问就是最高权限，
如果真不小心被发现的话，可以写一个计划任务，就是定时创建该账号，被删除后自动重新创建（除非把计划任务删了）
有的系统，管理员可能设置禁止root登录，可以修改一下，使其允许root登录
