第七章 Linux操作系统常见的命令

一、文件目录操作（基础）

命令

作用

示例



ls

列出目录内容

ls -la 显示所有文件（含隐藏）+ 详细信息



cd

切换目录

cd /home、cd ..、cd ~



pwd

显示当前路径

直接执行



mkdir

创建目录

mkdir -p a/b/c 一次性创建多级



rm

删除文件/目录

rm -rf 强制递归删除（危险）



cp

复制

cp -r 复制目录



mv

移动/重命名

mv a.txt b.txt 重命名



touch

创建空文件

touch test.txt



cat

查看完整文件

cat /etc/passwd



more / less

分页查看

空格翻页，q 退出



head / tail

查看头/尾

tail -f 实时跟踪日志（必考）



find

搜索文件

find / -name "*.log"



grep

搜索文本内容

grep -n "error" app.log



which

查命令所在路径

which java



作用

十一、面试版

面试的时候很有可能就会考实操，这个的话，要多加练习。

以下是deekseek生成的一部分：

需求

命令



查 8080 端口谁占了

netstat -tlnp | grep 8080



查 Java 进程

ps -ef | grep java



杀掉一个 Java 进程

ps -ef | grep java 查 PID，然后 kill -9 PID



实时看日志

tail -f /var/log/xxx.log



查磁盘满了没

df -h



查内存剩多少

free -h



从远程下载文件

wget http://xxx/file.tar.gz



复制整个文件夹到另一台机器

scp -r /root/folder root@192.168.1.2:/tmp



打包压缩整个目录

tar -czvf backup.tar.gz /var/log



解压 tar.gz 到当前目录

tar -xzvf backup.tar.gz



解压 zip

unzip file.zip



找 .log 结尾的文件

find / -name "*.log"



在日志里搜 error

grep -n "error" app.log



改文件权限为 755

chmod 755 file



把文件所有者改成 root

chown root file



看当前目录有几个文件/文件夹

ls -l | wc -l



查看历史命令

history



重复执行上一个命令
