5 .Tomcat安装部署

> 我已经成功在 CentOS 上装好了 Tomcat，并且能在浏览器里看到那只猫的首页。现在你有一个可以运行 Java Web 程序的服务器环境了。

> Tomcat 是一个 Web 应用服务器，本身不是网页形式。它运行在后台，是命令行形式的程序，和Nginx、MySQL。

> Tomcat 是一个让 Java 写的网站能运行起来的服务器软件。 写一个 Java Web 程序，把它放到 Tomcat 里，用户就能通过浏览器访问了。

> 那为什么能看到 Tomcat 首页？

Tomcat 启动后，它会把一个 管理网站 部署在自己的服务里，让你通过浏览器访问它，方便做管理和监控。

6 .Nginx安装部署

> Nginx 和 Apache 都是 Web 服务器软件。

> 他们没有图形化页面，使用的时候需要配合其他图形化软件（phpstudy、宝塔面板等）或终端敲命令。

> 它们的主要工作是：当你在浏览器输入网址，它们负责把网页内容传回来给你。

> 他们不仅具有正向代理功能，也有反向代理功能

7 .RabbitMQ的安装部署
（版本不匹配，我centos 10版本不匹配，需要用到docker，Docker母公司在美国 官方服务器在国外，在国内访问不稳定，而且这是在虚拟机里面 速度超级无敌慢；暂时跳过这个东西的安装）
> Docker是什么？作用？
Docker 是一个容器化平台，说白了就是一个能把应用及其依赖环境一起打包、独立运行的工具。
Docker = 轻量级的"虚拟机"，主要作用就是：服务器或虚拟机，安装软件时，解决版本不匹配的问题（比如：......）和端口冲突或其他依赖冲突的问题（比如：MySQL5.7和MySQL8.0端口冲突，都是3306端口）
Docker 不挑系统，任何系统都能装。你在虚拟机里装是因为学习 Linux，但日常开发直接用 Windows 版也行。
Docker 本质上就是运行在 Linux 上的，Docker 在 Windows 和 macOS 上本质还是运行在一个轻量级 Linux 虚拟机里。
> RabbitMQ是什么？作用？
RabbitMQ 就是让系统之间通过"消息"通信，相当于一个中转站，而不是直接相互调用，让系统更稳定、响应更快。
RabbitMQ 本质是一个应用程序， 和MySQL一样。
Linux 绝大多数命令（包括MySQL、Nginx、RabbitMQ，还有接下来我要安装的东西2）是磁盘上的独立程序文件（如 /bin/ls），极少数是 Shell 本身内置的（如 cd、exit），没有独立文件。
RabbitMQ 的中文翻译是 “兔子消息队列”；Robot 是"机器人"

8 .Redis的安装部署
Redis 是一个内存数据库（也叫键值存储数据库），数据主要存储在内存中，所以读写速度极快。
全称：REmote DIctionary Server（远程字典服务器）
Redis 的核心作用就是：把数据放在内存里，实现超高速读写。 给网站/应用装上一个"加速器"，让用户访问更快（可以配合MySQL使用）。


临时存储
存登录状态（Session）、秒杀库存、实时排行榜等需要快速读写的数据
