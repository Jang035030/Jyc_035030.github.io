二 、CentOS软件安装

1 .安装所需要的命令
yum：RPM包软件管理器，用于自动化安装配置Linux软件，并可以自动解决依赖问题。
语法：yum [-y］[install | remove | search］软件名称
选项：-y，自动确认，无需手动确认安装或卸载过程
install:安装、remove：卸载、search:搜索
可以su切换到root，或使用sudo提权。
yum命令需要root权限，yum命令需要联网
2 .要安装的软件
> wget
在 CentOS 虚拟机里，wget 是一个命令行下载工具，它的核心作用就是从网络上下载文件。
安装它，就是为了让虚拟机拥有“从互联网或内网服务器拉取文件”的能力，几乎所有Linux服务器都会装。
yum -y install wget
yum -y remove wget
yum -y search wget
> yum -y install ntp,安装ntp软件
可以通过ntpd服务名，配合systemctl进行控制
从 CentOS 8 开始，官方源已经移除了 ntp，改用 chrony 作为默认的时间同步工具。你用的应该是 CentOS 8 或更高版本，比如 CentOS Stream 9
> yum -y install httpd,安装apache服务器软件
可以通过httpd服务名，配合system ctl进行控制
3 .乌班图系统安装软件
Centos使用yum管理器，Ubuntu使用apt管理器
语法：apt [-y］[install | remove丨search］软件名称
用法和yum一致，同样需要root权限
apt install w get,安装wget
apt remove w get,移除wget
apt search w get,搜索wget
三 、systenctl命令
Linux系统很多软件（内置或第三方）均支持使用systemctl命令控制：启动、停止、开机自启
能够被systemctl管理的软件，一般也称之为：服务
语法：systemctl start | stop | status | enable | disable 服务名
系统内置的服务比较多，比如：
Network Manager，主网络服务
network，副网络服务
firewall d，防火墙服务
sshd，ssh服务（Final Shell远程登录Linux使用的就是这个服务）
----
start启动
stop关闭
status查看状态
enable开启开机自启
disable关闭开机自启

五 、日期和时区

1 .date命令
通过date命令可以在命令行中查看系统的时间
语法：date [-d] [+格式化字符串］
-d 按照给定的字符串显示日期，一般用于日期计算
格式化字符串：通过特定的字符串标记，来控制显示的日期格式
%Y 年
%y 年份后两位数字（00..99）
%M 月份（01..12）
%d 日（01.31）
%H 小时（00.23）
%M 分钟（00..59）
%S 秒（00.60）
%s 自 1970-01-0100:00:00 UTC 到现在的秒数（时间戳）
时间戳，说白了就是一串数字，用来代表某个特定的时刻。
在Linux和计算机世界里，最常见的时间戳是Unix时间戳（也叫Epoch时间）。它指的是：从1970年1月1日 00:00:00 UTC（协调世界时）开始，到当前时刻所经过的秒数（或毫秒数）
示例：
date
date +%Y-%m-%d
date "+%Y-%m-%d %H:%M:%S"
date +%Y-%m-%d\ %H:%M:%S
2 .-d命令，做日期计算
-d选项，可以按照给定的字符串显示日期，一般用于日期计算
其中支持的时间标记为：
year年
month月
day天
hour小时
minute分钟
second秒
-d选项可以和格式化字符串配合一起使用哦
示例：
date -d "+1 day" +%Y-%m-%d# 显示后一天的日期
date -d "-1 day" +%Y-%m-%d# 显示前一天的日期
date -d "-1 month" +%Y-%m-%d# 显示上一月的日期
date -d "+1 month" +%Y-%m-%d# 显示下一月的日期
date -d "-1 year" +%Y-%m-%d# 显示前一年的日期
date -d "+1 year" +%Y-%m-%d# 显示下一年的日期
下面简单的命令也生效：
date -d "+1 day"、date -d "-1 day"、date -d "-1 month"、date -d "+1 month"
date -d "-1 year"、date -d "+1 year"
3 .修改Linux时区
1> UTC 不是某个国家的时区，而是世界标准时间（Coordinated Universal Time）的缩写。
可以把它理解为全球时间的“母版”或基准线。全世界所有时区的时间，都是以 UTC 为基础加减小时数计算出来的。
特点：UTC 是0时区的时间，它不随季节变化，没有夏令时
2 > 中国标准时间（CST）= UTC + 8
意思就是：中国的时间比 UTC 快 8 个小时。
3> 用这个命令查看你系统当前设置的时区
timedatectl
4> 在中国，CST 确实指中国标准时间（UTC+8），但它在全球并不是中国独有的
通过date查看的日期时间是不准确的，这是因为：系统默认时区不是中国的东八区，而是UTC
（但是，我安装的centos虚拟机，因为版本比较新。显示的就是东八区，不用修改）
使用root权限，执行如下命令，修改时区为东八区时区
rm-f/etc/local time
sudo ln-s/us r/share/zone info/Asia/Shanghai /etc/local time
将系统自带的local time文件删除，并将/usr/share/zone info/Asia/Shanghai文件链接为local time文件即可

七 、网络传输

1 .ping命令
可以通过ping命令，检查指定的网络服务器是否是可联通状态
语法：ping [-c num] ip或主机名
选项：-C，检查的次数，不使用-C选项，将无限次数持续检查
参数：ip或主机名，被检查的服务器的ip地址或主机名地址
示例：
ping www.baidu.com
ping 192.168.228.130
ping -c 3 192.168.1.13（-c 是在linux操作系统里的）
ping -n 3 192.168.228.130（-n 是在windows操作系统里的）
2 .wget命令
wget是非交互式的文件下载器，可以在命令行内下载网络文件
语法：wget [-b] url
选项：-b，可选，后台下载，会将日志写入到当前工作目录的wget-log文件
参数：url，下载链接
示例:
wget https://nginx.org/download/nginx-1.24.0.tar.gz
3 .curl命令
curl可以发送http网络请求，可用于：下载文件、获取信息等
curl类似于用浏览器去打开网站，curl 就是一个在命令行里运行的、不带界面的“浏览器
语法：curl [-o] url
选项：-O，用于下载文件，当url是下载链接时，可以使用此选项保存文件
参数：url，要发起请求的网络地址
示例：
curl https://www.baidu.com （发送 HTTP 请求，获取网页内容并打印到屏幕）
curl -O https://nginx.org/download/nginx-1.24.0.tar.gz （下载文件，使用 -O 选项）
curl -o mynginx.tar.gz https://nginx.org/download/nginx-1.24.0.tar.gz （下载文件并重命名，使用 -o 小写）
4 .端口
> 端口，是设备与外界通讯交流的出入口。端口可以分为：物理端口和虚拟端口两类
物理端口：又可称之为接口，是可见的端口，如USB接口，RJ45网口，HDMI端口等
虚拟端口：是指计算机内部的端口，是不可见的，是用来操作系统和外部进行交互使用的
> 操作系统，可以支持65535个端口，这6万多个端口分为3类进行使用：
公认端口：1~1023，通常用于一些系统内置或知名程序的预留使用，如SSH服务的22
端口，HTTPS服务的443端口，非特殊需要，不要占用这个范围的端口。
注册端口：1024~49151,通常可以随意使用，用于松散的绑定一些程序、服务。
动态端口：49152~65535，通常不会固定绑定程序，而是当程序对外进行网络链接时，
用于临时使用（比如 自己搭建网站等）。
（无论是 Linux、Windows、macOS 还是其他系统，都严格遵循这个标准）
> nmap命令，查看端口占用情况
安装 sudo yum -y install nmap
语法 nmap 被查看的IP地址
示例：
nmap 127.0.0.1
nmap 192.168.228.130（也可以直接输入自己的IP）
nmap 192.198.1.13（理论上可以在centos虚拟机里面测试主机IP 仅桥接模式。但是不在同一个网段不行；主机每开机不写；对方有防火墙拦截或安全软件防护不行）
> netstat命令
可以通过netstat命令，查看指定端口的占用情况
先安装sudo yum -y install net-tools（我这个centos虚拟机是自带的）
语法：netstat -tlnp | grep 端口号
示例：
netstat -anp|grep 22
netstat -anp|grep 631
netstat -anp|grep 9090
上面的命令会出来很多，下面的页面会更加干净（只显示 TCP 网络端口）

netstat -tlnp | grep 631
netstat -tlnp | grep 9090

八 、进程管理

1 .什么是进程？

进程就是跑起来的程序。你每敲一个命令，系统就创建一个进程来为你服务，执行完再把它销毁。进程是由操作系统来控制的。因为操作系统是多任务的，进程就是让这些任务互不干扰、同时运行的基础单位。

每个进程都会有一个独有的：进程ID（进程号）

2 .进程可以通过任务管理器查看

打开任务管理器的方法：

> win11中，CTRL + SHIFT + ESC

> Linux操作系统中，使用htop命令
需要先安装sudo yum install epel-release -y、sudo yum install htop -y
然后 终端里面直接htop （即可启动）
按 F6：按指定列（如 CPU、内存）排序。
按 F4：输入关键词过滤进程（比如过滤 ssh）。
按 F9：结束选中的进程。
按 q：退出 htop
3 .ps命令
可以通过ps命令查看Linux系统中的进程信息
语法：ps [-e -f]
选项：-e，显示出全部的进程
选项：-f，以完全格式化的形式展示信息（展示全部信息）
一般来说，固定用法就是：ps-ef列出全部进程的全部信息
示例：
ps -ef
ps -ef | grep 进程英文名（直接ps -ef 会出来很多，可以配合管道符过滤一下，查看指定的）
ps -ef | grep tali
ps -ef |grep “16:50”（过滤掉16：50时刻的进程。说白了就是可以任意过滤）
4 .kill命令
在Linux中，可以通过kill命令关闭进程。
语法：kill [-9］进程ID
选项：-9，表示强制关闭进程。不使用此选项会向进程发送信号要求其关闭，但是否关闭看进程自身的处理机制。
示例：
kill -9 1123
kill 7133
（补充一下，这个命令可以查看进程ID ：ps -ef | grep sshd）

十 、环境变量

1 .什么是环境变量？

环境变量是操作系统（WindoWs、Linux、Mac）在运行的时候，记录的一些关键性信息（本质上是内存中的一串字符串），用以辅助系统运行。

我们使用的一系列命令其实本质上就是一个个的可执行程序（Windows、Linux、macOS所有操作系统都是）

比如，执行cd命令，本质上是运行/usr/bin/cd这个程序文件
并且，无论当前目录在哪里，不论处于什么文件夹下，都能执行cd命令等（准确来说是PATH这个环境变量），这就是环境变量的作用。
2 .env命令
查看当前系统中记录的环境变量
环境变量的本质就是：一堆字符串
示例：
env
env | grep PATH（管道符查看指定的PATH环境变量）
PATH是环境变量的一种；DHCP是动态获取服务器的IP，把它关了 那么电脑的IP就固定了。
3 .$符号
用于取环境变量的值（就是查看某个环境变量的意思）
语法： echo $环境变量英文名
示例：
echo $PATH
echo ${PATH}ABC（在输出结果后面拼接上ABC。语法正确，输出正确，但是没啥用）
4 .export命令
> export命令可以“自己设置/添加环境变量”
(临时生效，就是关机 下次开机就没有了)
语法：export MYNAME-自己起一个英文名
echo $MYNAME（这个是查看是否设置成功）
示例：
export MYNAME-Jang
echo $MYNAME
> 如何永久生效？
针对当前用户永久生效（vim命令去配置；vim ~/.bashrc文件，
也就是vim /home/centos/.bashrc）
针对所有用户永久生效（vim命令去配置；vim /etc/profile文件）
具体怎么配置问AI，我暂时也用不上（重启才能生效）。
> 自定义环境变量PATH
就是在PATH里面加上自己编写的程序（echo $PATH后，输出页面会比原来多出一个自己添加的东西）

十二 、Linux里面进行文件压缩、解压

1 .文件类型介绍

gzip、zip、tar.gz是压缩文件包，把它们解压缩后，就能得到里面的各种文件和文件夹。

tar是只打包不压缩，gzip、zip、tar.gz打包又压缩

使用场景：

想把整个文件夹打包带走（体积无所谓）→ 用 tar

想压缩一个超大日志文件 → 用 gzip

要发给用 Windows 的朋友 → 用 zip

在 Linux 服务器上备份/部署项目 → 用 tar.gz

工具

一句话概括



tar

打包：把多个文件/文件夹合并成一个大文件（.tar），但体积不变，不压缩。



gzip

压缩：把单个文件体积变小（.gz），但不能打包多个文件。



zip

打包 + 压缩：把多个文件/文件夹合并并压小（.zip），Windows 双击就能解压。



tar.gz

tar + gzip 组合：先打包，再压缩，Linux 最常用的压缩包格式





2 .tar命令
Linux系统常见的格式为：.tar、.gzip、.tar.gz
tar命令是针对这三种格式来进行压缩和解压缩的
语法：tar [-c -v -x -f -z -C] 参数1 参数2 ... 参数N
-c, 创建压缩文件，用于压缩模式
-v, 显示压缩、解压过程，用于查看进度
-x, 解压模式
-f, 要创建的文件，或要解压的文件，-f选项必须在所有选项中位置处于最后一个
-z, gzip模式，不使用-z就是普通的.tar格式
-r
-C, 选择解压的目的地，用于解压模式
{
-z选项如果使用的话，一般处于选项位第一个
-f选项，必须在选项位最后一个
}
示例：
tar -czvf /tmp/backup_20260112.tar.gz /home/centos/projects/
/var/log/nginx/ /etc/nginx/nginx.conf
3 .zip命令
Linux系统中，压缩为.zip格式，tar命令不行，就要用到zip命令（只能压缩，不能解压）
语法：zip [-r］参数1 参数2 ... 参数N
-r，被压缩的包含文件夹的时候，需要使用-r选项，和rm、cp等命令的-r效果一致
示例:
zip test.zip a.txt b.txt c.txt（ 将a.txt b.txt c.txt压缩到test.zip文件内）
zip-r test.zip test itheima a.txt（将test、it heim a两个文件夹和a.txt文件，压缩到test.zip文件内）
4 .unzip命令
unzip命令，是用来解压缩.zip格式的
语法：unzip［-d] 参数
-d，指定要解压去的位置，同tar的-C选项
参数，被解压的zip压缩包文件
示例:
unzip test.zip （将test.zip解压到当前目录）
unzip test.zip -d/home/itheima将test.zip解压到指定文件夹内，即：/home/it heima
